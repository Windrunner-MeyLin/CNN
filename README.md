# 卷积神经网络（CNN）在图像分类任务中的全生命周期应用
本项目核心聚焦于如何利用CNN自动化的层次化特征提取能力，解决从标准数据集到真实场景的识别挑战。我们基于PyTorch框架，针对MNIST灰度手写数字与CIFAR-10彩色物体两类经典任务，完整演示了CNN架构的灵活适配——包括根据输入维度（单/三通道）动态调整网络首层、通过卷积核滑动提取局部边缘与纹理特征、并利用池化层逐步降维以获取平移不变性。面对真实手写照片与标准数据集存在的分布偏移，项目深入实践了CNN的**迁移学习应用**：通过冻结预训练模型的深层卷积基干（保留其作为通用特征提取器的能力），仅对全连接分类层进行微调，有效解决了小样本自定义数据泛化性差的痛点。最终，我们将训练好的CNN模型封装为针对单张和批量图像的推理接口，在真实噪声环境下验证其分类鲁棒性，完整覆盖了从数据预处理、网络结构设计、超参数调优到模型部署的CNN工程闭环，充分彰显了CNN作为现代计算机视觉基石的实际应用价值。
